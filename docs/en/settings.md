# Settings

English | [Simplified Chinese](../settings.md)

Open Settings using the gear on the main screen. About Dukto2 is at the bottom; receiving-folder controls are not duplicated on the main screen.

| Setting | Behavior |
| --- | --- |
| Receiving location | Select / remember a folder or restore default; existing files stay in place |
| Device name | Read-only name returned by the system, refreshed on startup and foreground resume; no in-app renaming |
| Completion notifications | Enable successful-send / receive reminders and inspect or request system permission |
| Language | Follows the system by default; select one of 10 languages, applied after saving and remembered across restarts |
| Appearance | System, light or dark, remembered after restart |
| About | Version, Dukto tribute, AI disclosure and third-party licenses |

Changing a system name does not change device identity or its certificate. iOS restricts access to custom names; see [Apple platforms](ios.md).

Completion messages omit filenames and text bodies. System permission, do-not-disturb and desktop notification services control actual display. Notification failure does not invalidate a completed transfer. Android's ongoing foreground-service notification, including progress and cancellation, is separate from completion reminders.

Linux exposes system notification settings only when supported by the desktop; Windows manages notification delivery. See [files and text](receive-and-text.md) for destinations and [batches and history](batch-and-history.md) for recent transfers.

Supported languages are Simplified Chinese, English, Spanish, Brazilian Portuguese, French, German, Russian, Japanese, Korean and Arabic. Automatic mode matches the system language preference list and falls back to English. Regional variants use the available translation (Simplified Chinese and Brazilian Portuguese). Arabic uses right-to-left layout; connection addresses and verification codes stay left-to-right.

Changing language preserves transfers, text drafts and history. Device names, filenames and actual paths remain unchanged. Completion messages and Android transfer notification actions use the app language. System file pickers and Apple permission prompts follow the operating system’s app-language setting.

Translations live in `lib/l10n/app_*.arb`, with typed interfaces generated by Flutter `gen-l10n`. After editing translations, run `./tool/flutterw gen-l10n` and `python3 tool/sync_native_localizations.py`, then `bash tool/check.sh`. Checks cover completeness, arguments, plurals, native permission resources and layouts. Keep keys and arguments in the Chinese and Portuguese base fallback catalogs in sync with their regional catalogs; regional wording may differ.
