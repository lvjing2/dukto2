# 接收位置与文本

[English](en/receive-and-text.md) | 简体中文

## 接收位置

在「设置 → 接收位置」更改文件夹或恢复默认。更改位置不会移动或删除已有文件，历史记录仍指向原位置；无法访问自选目录时提示重新选择。

| 平台 | 默认位置 | 目录授权 |
| --- | --- | --- |
| macOS | 下载 / Dukto2 | 系统目录选择器与安全书签 |
| Windows / Linux | 下载 / Dukto2 | 系统目录选择器与本机路径 |
| Android 10+ | 下载 / Dukto2 | 默认 MediaStore，自选目录使用 SAF 持久授权 |
| Android 7–9 | 应用内目录 | 授权 SAF 文件夹后可直接接收 |
| iPhone / iPad | 文件 → 我的 iPhone / iPad → Dukto2 → 接收文件 | 系统目录选择器与安全书签 |

文件采用独立接收目标处理重名，不覆盖已有文件。长度与 SHA-256 校验、提交完成后才记录成功；未完成的目标会清理，已提交文件不会因取消而删除。平台存储细节见 [可靠性说明](reliability.md)。

## 文本

选择并核对设备后，切换到「文本」，输入内容或点击粘贴，再点击发送。接收方确认后可在最近传输中查看与复制。应用不会自动读取或同步剪贴板。

- 上限为 16 MiB UTF-8 字节，编辑区适合 1 MiB 以内的文本。
- 更大文本通过「更多文本操作 → 载入文本文件」流式发送。
- 超过 1 MiB 的接收正文保存到接收位置，历史保留有界预览，可复制预览或打开完整文本。
- 手机打开键盘后使用紧凑编辑布局；收起键盘保留草稿和页面位置。
- 系统剪贴板的可用容量仍由操作系统决定。

手动连接支持 IPv4 与端口，对全角数字、冒号和句点进行归一化后再严格校验。连接前仍需核对设备身份。
