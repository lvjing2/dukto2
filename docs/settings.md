# 设置

[English](en/settings.md) | 简体中文

主界面点击齿轮进入设置。「关于 Dukto2」位于设置页底部，接收位置不在主界面重复展示。

| 项目 | 行为 |
| --- | --- |
| 接收位置 | 更改文件夹、记住授权或路径、恢复默认；不移动已有文件 |
| 设备名称 | 只读展示系统允许返回的名称；启动及恢复前台时刷新，不提供应用内改名 |
| 传输完成通知 | 控制成功发送和接收后的提醒；查看或申请系统权限 |
| 外观 | 跟随系统、浅色或深色，重启后保留 |
| 关于 | 版本、Dukto 致谢、AI 创作声明及第三方许可 |

设备名称变化不更换设备身份或证书。iOS 对读取自定义名称有限制，见 [Apple 平台说明](ios.md)。

完成通知使用通用文案，不包含文件名或文本正文；系统权限、勿扰模式和桌面通知服务决定实际展示。通知失败不影响已完成的传输。Android 正在传输时的前台服务通知独立于完成提醒开关，包含进度与取消操作。

Linux 的系统通知设置入口按桌面能力显示；Windows 通知由系统管理。接收位置和平台差异见 [文件与文本](receive-and-text.md)，最近传输的筛选与布局见 [批量与历史](batch-and-history.md)。
