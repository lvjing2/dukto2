# 设置

[English](en/settings.md) | 简体中文

主界面点击齿轮进入设置。「关于 Dukto2」位于设置页底部，接收位置不在主界面重复展示。

| 项目 | 行为 |
| --- | --- |
| 接收位置 | 更改文件夹、记住授权或路径、恢复默认；不移动已有文件 |
| 设备名称 | 只读展示系统允许返回的名称；启动及恢复前台时刷新，不提供应用内改名 |
| 传输完成通知 | 控制成功发送和接收后的提醒；查看或申请系统权限 |
| 语言 | 默认跟随系统；可选择 10 种语言，保存成功后即时切换，重启后保留 |
| 外观 | 跟随系统、浅色或深色，重启后保留 |
| 关于 | 版本、Dukto 致谢、AI 创作声明及第三方许可 |

设备名称变化不更换设备身份或证书。iOS 对读取自定义名称有限制，见 [Apple 平台说明](ios.md)。

完成通知使用通用文案，不包含文件名或文本正文；系统权限、勿扰模式和桌面通知服务决定实际展示。通知失败不影响已完成的传输。Android 正在传输时的前台服务通知独立于完成提醒开关，包含进度与取消操作。

Linux 的系统通知设置入口按桌面能力显示；Windows 通知由系统管理。接收位置和平台差异见 [文件与文本](receive-and-text.md)，最近传输的筛选与布局见 [批量与历史](batch-and-history.md)。

支持简体中文、英语、西班牙语、巴西葡萄牙语、法语、德语、俄语、日语、韩语和阿拉伯语。自动模式按系统语言偏好匹配；不支持的语言回退到英语。同语言的区域变体使用现有译文（中文为简体、葡萄牙语为巴西版）。阿拉伯语采用从右向左布局，连接地址与核对码保持从左向右。

切换语言不重启传输服务，不清空文本草稿或传输记录，也不改动设备名称、文件名和真实保存路径。完成通知及 Android 前台通知操作使用 App 语言；系统文件选择器和 Apple 权限弹窗遵循操作系统的应用语言设置。

译文源文件位于 `lib/l10n/app_*.arb`，使用 Flutter `gen-l10n` 生成类型化接口。修改译文后运行 `./tool/flutterw gen-l10n` 和 `python3 tool/sync_native_localizations.py`；再运行 `bash tool/check.sh`，检查完整性、参数、复数、原生权限文案与界面布局。中文和葡萄牙语的基础回退模板应与对应区域模板保持相同的键和参数，措辞可以存在区域差异。
