## Features

- Cross-platform LAN transfers for files, text and file batches.
- Automatic discovery, manual addresses and QR connections with device identity verification.
- Remember the receiving folder, filter transfer history by device, and show completion times and durations.
- Ten interface languages, with light and dark themes.

## Fixes and improvements

- Improve session and resource cleanup after failed or cancelled transfers, with clearer errors.
- Refine layouts for narrow phone screens, large text and the on-screen keyboard.

Download packages from Assets. macOS is not notarized; the iOS attachment is an unsigned development build. See the [installation and validation notes](https://github.com/lvjing2/dukto2/blob/main/docs/releases/v0.1.6-rc.2-details.md).
