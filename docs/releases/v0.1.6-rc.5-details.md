# Dukto2 0.1.6-rc.5 构建与验证记录

版本 `0.1.6-rc.5+12`，标签 `v0.1.6-rc.5`，源码提交 `0c36dbba302f1162f2556de291edf378d563639b`。仓库保持 private，Release 保持 Draft / Prerelease；此前 Git 标签不变。

## 附件

- Android 通用 APK：手机和平板共用，沿用应用密钥；Play AAB 仍保留在 CI，使用上传密钥。
- Windows x64、Windows ARM64：各一个完整 ZIP，保留 DLL 和 data；包含对应 Visual C++ Release 运行库，未做商业代码签名。ARM64 目标为 Windows 11。
- Linux x64、Linux ARM64：各一个 TAR.GZ，包含桌面安装入口；基线 Ubuntu 24.04，依赖系统 GTK3 / glibc。
- macOS：一个通用 ZIP，ad-hoc 签名，未公证。
- iPhone / iPad：一个未签名 device build ZIP，需开发者自行签名，不是可直接安装的 IPA。

共七个附件。桌面及 iOS 压缩包包含内部校验清单与来源信息；APK 保持原始签名字节。完整签名报告、AAB 与外置校验文件保留在 CI。

## 验证边界

本机与 CI 检查通过：21 项 Python 脚本测试、134 项应用测试、49 项核心测试。新增测试覆盖原生二进制识别和混合架构运行库拒绝。

ARM64 采用原生 GitHub Runner；SDK 从同一固定提交的官方 Flutter 源码启动原生 Dart，禁止 x64 回退。构建与打包检查实际主程序、Flutter 引擎、插件及运行库架构。Windows ARM64 排除 MSVC 目录附带的 x64 专用异常处理组件，并检查原生 DLL 的导入表，防止排除实际依赖。

[七项原生构建及草稿汇总](https://github.com/lvjing2/dukto2/actions/runs/39408684830) 全部通过。七个最终附件与 GitHub 上传摘要一致，内部校验清单、来源提交和版本一致；Windows/Linux 两种架构实际二进制均已核对，macOS 最终附件签名验证通过。旧版五个附件备份、核对后已从草稿移除。详细大小和摘要见 [验证 JSON](v0.1.6-rc.5-validation.json)。本次未重复跨端设备测试；ARM64 桌面启动、摄像头、系统权限及局域网互传尚待真机验证。历史结果见 [验证范围](../validation.md)。
