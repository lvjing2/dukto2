# Dukto2 0.1.6-rc.5 build and validation record

Version `0.1.6-rc.5+12`, tag `v0.1.6-rc.5`, source commit `0c36dbba302f1162f2556de291edf378d563639b`. At validation time, the repository was private and the release remained a Draft / Prerelease. Previous Git tags were unchanged.

## Attachments

- Android: universal APK for phones and tablets, retaining the application key. The Play AAB remains in CI and uses the upload key.
- Windows x64 and ARM64: one complete ZIP per architecture; retain DLL/data files. Includes the matching Visual C++ Release runtime; not commercially code-signed. ARM64 targets Windows 11.
- Linux x64 and ARM64: one TAR.GZ per architecture, including desktop installation support. Ubuntu 24.04 baseline; system GTK3/glibc dependencies apply.
- macOS: one universal ZIP, ad-hoc signed and not notarized.
- iPhone / iPad: one unsigned device-build ZIP requiring developer signing, not a directly installable IPA.

Seven attachments in total. Desktop and iOS archives include internal checksum manifests and provenance metadata. The APK retains its original signed bytes. Full signing reports, the AAB and external checksum files remain in CI.

## Validation scope

Local and CI checks passed: 21 Python script tests, 134 application tests and 49 core tests. Added tests cover native binary identification and rejection of mixed-architecture runtime libraries.

ARM64 uses native GitHub runners. The SDK bootstraps native Dart from the same pinned official Flutter source commit, without an x64 fallback. Build and packaging checks verify the actual executable, Flutter engine, plugins and runtime architectures. Windows ARM64 excludes the x64-only exception-handling helper included in MSVC directories and checks native DLL import tables to prevent excluding a required dependency.

[Seven native builds and draft assembly](https://github.com/lvjing2/dukto2/actions/runs/39408684830) all passed. All seven final attachments matched GitHub upload digests, internal checksum manifests, source commits and versions. Windows/Linux binaries were checked for both architectures, and the final macOS archive passed signature verification. The five older attachments were backed up and verified before removal from the draft. See the [validation JSON](v0.1.6-rc.5-validation.json) for sizes and digests. This round did not repeat cross-device tests. ARM64 desktop startup, cameras, system permissions and LAN transfers remained pending hardware validation.
