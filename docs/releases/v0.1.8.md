## Improvements

- Add a localized Android first-launch privacy dialog over a presentation-only home screen. Discovery, transfer and scanner initialization wait for explicit consent.
- Add an easily accessible privacy-policy link in Settings, with localized labels and a copyable address when the browser cannot open.
- Disclose scanner orientation-sensor use and defer automatic ML Kit initialization until after consent.
- Update author credits to Zhao Zhenling (lvjing2), linking to the GitHub profile.
- Add a Windows x64 EXE installer with per-user installation, Start menu shortcut and uninstall support. Portable x64 and ARM64 ZIP downloads remain available.

## Validation and limitations

- Application, core, native privacy and release-tool checks run before packaging. Windows installer CI checks installation, complete payload hashes, reinstall and uninstall.
- The previous Android build 22 was tested on a physical device for privacy choice, camera denial/acceptance, rotation and same-signature upgrade preserving history, settings and identity. Build 23 changes the privacy presentation and author credit; those UI changes have host-test coverage, not a new physical-device acceptance pass.
- Android background reception remains optional and **off by default**, with the existing 30-minute limit and manufacturer power-management restrictions.
- Windows packages have no publisher certificate; macOS remains ad-hoc signed and unnotarized. Unsigned iPhone/iPad builds remain in CI and are not public installable downloads.
- Store review and copyright paperwork are still pending. CI checks do not establish store approval or physical-device transfer acceptance on every platform.

Version: 0.1.8, build 23. The Android APK retains the existing production application-signing identity.
