# Dukto2 0.1.6-rc.3 release and validation record

Version `0.1.6-rc.3+10`, tag `v0.1.6-rc.3`, source commit `1ae3b37ed1107611895ee06ea6e8bb6815f06816`. At validation time, the repository was private and the release remained a Draft / Prerelease. Subsequent updates to this record do not change the tag.

## Packages

- Android: universal APK using the existing application signing key. The Play AAB uses the separate upload key and remains in CI artifacts. Build number: 10.
- Windows x64: fully extract the ZIP before running `Dukto2.exe`; retain all DLL and data files. Includes the VC++ Release runtime; not commercially code-signed.
- Linux x64: fully extract the archive and follow the included instructions to launch or install a desktop entry. Ubuntu 24.04 baseline; system GTK/glibc dependencies still apply.
- macOS: ad-hoc signed, not notarized. This does not establish Intel hardware acceptance.
- iPhone / iPad: unsigned device build for developers to sign with Xcode; not an installable IPA, TestFlight or App Store release.

The release retains one attachment per platform. Desktop archives include `RELEASE-INFO.json`, licenses and an internal `SHA256SUMS.txt`. The APK retains its original signed bytes; its digest, full build metadata, AAB and signing reports remain in CI.

## Validation scope

Local checks passed 134 application tests, 49 core tests and 18 script tests. The actual Mac GUI was tested against a controlled loopback TLS endpoint for online status, disabled sending after disconnection and recovery after reconnection. Language-list layout checks covered the actual text of all ten languages.

[Five-platform native builds and draft assembly](https://github.com/lvjing2/dukto2/actions/runs/39398667423) all passed. Upload digests, original CI digests and internal manifests were verified for all five final attachments. Android APK bytes were unchanged; application/upload certificate identities were preserved, and the AAB-derived APK passed checks. The final macOS archive passed signature verification and contains `x86_64 arm64`; iOS was confirmed as an unsigned development build. Versions, sizes, SHA-256 digests and public certificate fingerprints are in the [validation JSON](v0.1.6-rc.3-validation.json). Previous draft attachments were backed up and removed; the original rc.2 Git tag was unchanged.

Native build success is not cross-device acceptance. Windows camera, tablet hardware and complete cross-platform transfers for this candidate remained pending revalidation once the environment was available. See [historical hardware coverage](../en/validation.md).

Resumable transfers, folder transfers, original Dukto compatibility and automatic updates are not implemented. Google Play setup, application signing-key import and real cross-channel upgrades remained pending.
