# Dukto2 0.1.6-rc.3 发布与验证记录

版本 `0.1.6-rc.3+10`，标签 `v0.1.6-rc.3`。仓库保持 private，Release 保持 Draft / Prerelease。源码提交 `1ae3b37ed1107611895ee06ea6e8bb6815f06816`；本文件的后续记录不改变该标签。

## 安装包

- Android：通用 APK，沿用现有应用签名；Play AAB 使用独立上传签名，保留在 CI 产物中。构建号为 10。
- Windows x64：完整解压 ZIP 后运行 `Dukto2.exe`，保留所有 DLL 与 data；包含 VC++ Release 运行库。未做商业代码签名。
- Linux x64：完整解压压缩包，按随包说明运行或安装桌面入口；基线 Ubuntu 24.04，仍需系统 GTK / glibc 依赖。
- macOS：ad-hoc 签名应用，未公证；不代表 Intel 真机已经验收。
- iPhone / iPad：未签名 device build，供开发者自行使用 Xcode 签名。不能直接当作可安装 IPA、TestFlight 或 App Store 版本。

Release 每个平台仅保留一个附件；桌面压缩包包含 `RELEASE-INFO.json`、许可及内部 `SHA256SUMS.txt`。APK 保持原始签名字节；其摘要、完整构建元数据、AAB 与签名验证报告保留在 CI。

## 验证边界

本机完整检查已通过 134 项应用测试、49 项核心测试和 18 项脚本测试。Mac 实际 GUI 已用可控回环 TLS 端点验证在线、断线禁用和重连恢复；语言列表覆盖十种语言的实际文字排版检查。

[五平台原生构建与草稿汇总](https://github.com/lvjing2/dukto2/actions/runs/39398667423) 全部通过。五个最终附件的上传摘要、原始 CI 摘要及内部清单均已核对；Android APK 字节未改变，应用和上传证书保持原身份，AAB 派生 APK 校验通过。macOS 最终附件解压后签名检查通过，主程序包含 `x86_64 arm64`；iOS 确认为未签名开发构建。版本、大小、SHA-256 和公开证书指纹见 [验证 JSON](v0.1.6-rc.3-validation.json)。旧草稿附件已备份并移除，原 rc.2 Git 标签未修改。

原生构建成功不等于跨设备验收：Windows 摄像头、平板硬件及本次候选的完整跨端互传仍待环境恢复后复验。历史设备结果见 [验证范围](../validation.md)。

尚无断点续传、文件夹传输、原 Dukto 协议兼容或自动更新。Google Play 建档、应用签名密钥导入及真实渠道覆盖升级仍待完成。
