# Dukto2 0.1.6-rc.2 发布与验证记录

发布候选 `0.1.6-rc.2+9`，源码标签 `v0.1.6-rc.2`，应用提交 `c6ed3ca87f6a2ef0b8c35fb9e9b442b400847abe`。仓库保持 private，本版本为 Draft / Prerelease，尚未向社区或应用商店正式发布。

本轮 CI：[五平台候选构建](https://github.com/lvjing2/dukto2/actions/runs/39209879206)。安装包版本、来源提交、架构及签名状态以附件 JSON 元数据为准；下载后核对对应 `.sha256`。

## 本轮验证结果

五个平台原生构建及草稿汇总均已通过。CI 完成 117 项应用测试、49 项核心测试、15 项工具测试，静态分析及 58 个 Dart 文件的格式检查通过。五份构建 JSON 均指向上述应用提交及 `0.1.6-rc.2+9`；Android 统一 versionCode 为 9，应用 / 上传证书和 AAB 派生 APK 身份验证通过。

macOS 主二进制包含 `x86_64 arm64`，这不代表 Intel 真机已验证。八个安装 / 许可 / 素材附件的 GitHub 上传摘要均已与 `.sha256` sidecar 核对。详细记录见 [验证 JSON](https://github.com/lvjing2/dukto2/blob/main/docs/releases/v0.1.6-rc.2-validation.json)。

## 本候选包含

- 局域网文件和文字直接传输、批量清单确认、接收目录记忆、传输时间与耗时、按设备筛选记录。
- 十种界面语言与原生通知本地化，浅色 / 深色外观。
- 附近设备发现、已知设备记录、手动地址及带完整指纹核验的二维码连接。
- Android APK 使用应用签名密钥，Play AAB 使用独立上传密钥；两者包名和构建号一致。

## 下载与安装

| 平台 | 附件及边界 |
| --- | --- |
| Android | `*-android.apk` 为通用安装包；`*-android-play.aab` 供未来 Play 上传，不能直接安装 |
| Windows x64 | `*-windows-x64.zip`，完整解压后运行，保留 DLL / data；未做商业代码签名，需要 VC++ x64 Runtime |
| Linux x64 | `*-linux-x64.tar.gz`，Ubuntu 24.04 构建基线；完整解压并按随包说明检查 GTK / glibc 依赖 |
| macOS | `*-macos-adhoc.zip`，ad-hoc 签名、未公证；实际架构见 JSON，Intel 尚未真机验证 |
| iPhone / iPad | `*-ios-device-unsigned.zip` 仅为开发者用无签名 device build，不能当作公众可安装 IPA 或 TestFlight 包 |
| 社区与商店素材 | `*-promotion.zip`：中文社区长短稿、安装反馈说明、原始 Android 截图、图标、功能图、中英文商店及隐私草稿 |

Android 现有 debug 安装与正式应用密钥不同，不能直接覆盖。此流程不会自动卸载或清空已有应用。Google Play 尚未创建应用或导入密钥，真实 Play ↔ GitHub 覆盖升级仍待验收。

## 实测与限制

完整分析、单元 / 界面测试、格式和原生构建结果见 CI。原生编译通过不代表本轮候选二进制已在所有设备完成 GUI、局域网或后台验收。历史真机覆盖见 [验证记录](https://github.com/lvjing2/dukto2/blob/main/docs/validation.md)。Android 社区截图来自已安装 0.1.6+7 开发构建，保留测试记录和原始分辨率，来源及摘要见素材包。

尚无断点续传、文件夹传输、旧 Dukto 协议兼容或自动更新服务。设备需直接可达，访客网络 / 路由器隔离可能阻止通信；后台持续运行受系统限制。Windows 10、Intel Mac、其他 Linux 发行版与老设备未作全面兼容承诺。

## 隐私与反馈

文件传输不经过维护者中继；局域网发现包含必要的设备元数据，本机保存设置和历史。Android 扫码依赖 ML Kit，含 Google 披露的 SDK 诊断 / 使用数据行为，不能宣称全部依赖“零采集”。隐私政策与数据安全核对稿在素材包中，公开政策网址和最终商店声明尚待完成。

支持邮箱：leojames.googol@gmail.com。反馈请附两端系统和版本、网络环境、复现步骤、文件数量和大小、错误提示；提交截图或日志前去除个人内容和凭证。
