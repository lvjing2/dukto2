## 改进

- 应用与发布元数据统一显示项目版本号，并精简无设备和无传输记录的状态。

- 点击刷新与触屏下拉刷新主动搜索附近设备，并显示正在搜索状态。
- 上线公告与正常退出离线广播；已发现设备每秒检查，连续 3 秒无法经 HTTPS 确认时移除。离线广播仅在端点检查失败后提前移除设备。
- 在线检查与候选扫描独立调度，减少扫描繁忙时的下线显示延迟。
- 精简已选设备信息和二维码扫描界面；「关于」显示作者链接与项目版本号。

Android 安装版本号升至 14，继续沿用现有应用签名与上传签名。提供 Windows / Linux x64、ARM64，macOS、Android 和 iOS 构建。ARM64 尚待真机验收；macOS 未公证；iOS 为需要自行签名的开发构建。系统暂停观察端时，计时和界面更新会在恢复运行后继续。

## Improvements

- Unify the displayed project version with release metadata and simplify empty-device and empty-history states.

- Actively search nearby devices from the refresh button or touch pull-to-refresh, with a searching indicator.
- Announce presence and graceful departure. Check discovered peers every second and remove them after three seconds without HTTPS confirmation; departure hints accelerate removal only after a failed endpoint check.
- Schedule presence checks independently of candidate scans to reduce offline-status delays during discovery.
- Simplify selected-device details and the QR scanner; display author links and the project version in About.

Android versionCode increases to 14 while retaining the existing application and upload signing keys. Builds cover Windows / Linux x64 and ARM64, macOS, Android and iOS. ARM64 hardware acceptance remains pending; macOS is not notarized; iOS requires developer signing. If the observing app is suspended by the OS, timers and UI updates continue when it runs again.
