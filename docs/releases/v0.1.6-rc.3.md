## New

- Windows camera QR scanning, QR recognition from images and touch layouts.
- Green indicators for online devices and gray indicators for offline devices. Disable sending when unreachable and restore it after reconnection.

## Fixes and improvements

- Move the device name to the first setting and align the language list.
- Bundle required Windows runtime libraries and add a Linux desktop installation entry point.

One attachment per platform. macOS is not notarized; iOS requires developer signing. See the [installation and validation notes](https://github.com/lvjing2/dukto2/blob/main/docs/releases/v0.1.6-rc.3-details.md).
