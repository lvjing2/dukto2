# Dukto2 商店素材（准备稿，未提交）

当前推广优先级为国内开发者社区试用；Google Play 等账号审核通过后继续。本目录保留中英文商店字段、现有 512×512 图标、两种语言的 1024×500 功能图，以及隐私政策和数据安全核对稿。

- listing.json：包名、候选来源、联系邮箱与待定公开政策网址。
- zh-CN/、en-US/：名称、短介绍、完整介绍、版本说明；可复制至未来 Console 表单。
- graphics/：icon-512.png 从项目现有方形 SVG 图标母版导出为 512×512 RGBA PNG；feature-*.svg 为本地原创矢量排版，feature-*.png 为其 RGB 导出。功能图是说明插画，不是应用截图。
- privacy-policy.*.md / .html：中英政策草稿，含实际扫码 SDK 披露。还未公开托管，不可填写私有仓库地址来代替政策网址。
- data-safety-worksheet.md：逐项证据及待确认项；不能一键照抄成“无采集”。

Android 原始真机图片放在 ../community-zh/screenshots/，保留原分辨率，不裁图、不伪造传输记录。手机已安装的 0.1.6+7 开发构建反映相同界面功能，不能据此宣称 rc.2 安装包通过真机互传。其超长画幅及状态栏尚未按 Play 规范重拍；不作为 Google Play 已验收截图。

正式商店提交前仍需公开政策网址、应用内政策入口、最终 SDK 数据行为复核、内容分级/目标受众问卷、必要的前台服务说明与录屏，以及 Play 的账号和应用签名配置。当前不代选或提交任何法律声明。
