# 候选版安装与反馈

版本：0.1.6-rc.2+9。仅使用对应附件及 SHA-256，不混用旧版二进制。安装前保留重要文件的其他副本，不把传输工具当作唯一备份。

| 系统 | 试用方式 / 当前限制 |
| --- | --- |
| Android | 下载已签名的通用 APK，在系统中允许本次来源安装。正式 APK 使用应用签名密钥；现有 debug 包签名不同，不能直接覆盖。应用不会替你卸载或清空开发包；先备份需要的内容，由你决定如何处理冲突。Android 7 起为目标范围，当前真机验证集中在 Android 16 |
| Windows | 解压完整 x64 zip，保留 DLL 与 data，再运行 Dukto2.exe。未做商业代码签名，系统可能提示未知发布者。需要微软 Visual C++ x64 Runtime；Windows 11 实测，Windows 10 尚未实测 |
| macOS | 解压完整 app。当前 ad-hoc 签名、未公证；分发前先了解系统来源提示，勿关闭全局安全保护。Apple Silicon 有真机记录，Intel 未实测 |
| Linux | 解压完整 x64 bundle，阅读库依赖和安装说明。Ubuntu 24.04 是当前构建/验证基线，其他发行版未作兼容承诺 |
| iOS / iPadOS | 本次未提供公众直接安装包；未签名 device build 仅供具备工具链的开发者后续签名测试 |

## 最小试用流程

1. 两台设备连接到允许互通的局域网，打开 Dukto2。
2. 选择设备并在接收设备屏幕上核对身份码；或扫对方 Dukto2 连接二维码。不要仅凭设备名称信任陌生设备。
3. 发送一个小文件，由接收端确认。检查文件大小与内容，再尝试批量文件和文字。
4. 试用接收目录设置、记录筛选、文字复制和取消操作。文件中断后需要重新发送。
