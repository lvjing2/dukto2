# 用 Flutter 做一个跨平台局域网传输工具：Dukto2 的实现与取舍

Dukto2 用 Flutter 承载桌面与移动界面，独立的 Dart 核心处理设备发现、身份与传输协议，平台层负责文件流和系统目录。目标是保留 Dukto 简单直接的使用方式。

这次实现里比较关键的几处：

- 自动发现只提供候选设备信息；连接核对身份后固定证书指纹，不能因名字相同就信任。
- 批量接收确认限定这次清单，不能沿用到后续陌生请求。
- 文件以有界缓冲流式读写，大小和 SHA-256 通过后才发布最终文件。
- Android 后台依赖前台服务和系统约束，不能承诺杀进程后续传。
- Windows 分发补齐 CRT DLL，Linux 检查运行库并注册桌面入口；CI 编译通过与真机安装通过分别记录。

当前已有文件、文本和批量传输，暂未实现断点续传。源码仍在整理，公开时间另行确认；先欢迎对安装流程、架构边界和局域网发现提出建议。
