# 界面规范

[English](DESIGN.en.md) | 简体中文

Dukto2 使用极简蓝色界面，系统字体与语义颜色，兼顾桌面信息密度、手机触控和大字体。

## 视觉与布局

- 主色 `#2563EB`，浅色、深色和跟随系统；成功与错误同时提供文字反馈。
- 间距以 4 / 8 / 12 / 16 / 24 / 32 为基础，弱边框、轻量圆角，避免装饰占据任务空间。
- 宽屏左侧为附近设备与本机信息，右侧为发送内容和最近传输；窄屏或大字体自然转为单列。
- 操作区域至少 48dp，文件名可换行，辅助技术保留完整名称。
- 系统字体不依赖联网下载；品牌图形见 [图标资源](app-icon/README.md)。

## 操作流程

选择设备 → 实际核对身份码 → 选择文件或文本 → 明确发送 → 接收方确认 → 上传与校验 → 完成。设备名称不证明身份，接收请求不自动同意。

本机信息展示身份码与地址，主屏不常驻长指纹。附近设备按类型显示手机、平板或电脑；缺失类型时使用通用图标。无设备时提供刷新与手动连接。

手机打开文本键盘后进入紧凑编辑态，发送工具栏位于键盘上方；收起键盘保留草稿和滚动位置。设置集中放置接收位置、系统名称、通知、外观及关于。

## 最近传输

名称与大小为第一层；「已发送 / 已接收 · 设备」为第二层。宽屏单独右对齐时间和耗时，窄屏自然换行。最右仅一个按钮：文本「查看文本」、文件「打开目录」。复制操作放在详情中，不重复占用列表空间。

记录时间、速度和进度来自真实传输状态，不展示演示数值。实际屏幕见 [应用截图](../docs/screenshots/README.md)，测试范围见 [验证说明](../docs/validation.md)。设计指导工具来源见 [AI 创作与致谢](../ACKNOWLEDGEMENTS.zh-CN.md)。
