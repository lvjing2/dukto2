## 视觉规则

- 浅色默认，提供深色对照；背景、表面、文字、边框与反馈颜色使用语义 token。
- 主色 `#2563EB`，深色主操作 `#93B4FF`；主操作突出，成功与错误同时有文字和图标。
- 使用系统字体：macOS 系统无衬线与中文 PingFang，Android Roboto / 系统中文。避免依赖联网字体。
- 文字层级：页面标题 24、区块 / 设备 16、正文 14–16、说明 12–13。手机正文 16。文件名可换行。
- 4 / 8 / 12 / 16 / 24 / 32 间距。列表优先，圆角 10–16，不使用大标语、装饰渐变或重阴影。
- 桌面以信息密度和键盘操作为先；Android 操作区域至少 48dp。尊重减少动态效果设置。

## 页面与流程

- macOS：左侧附近设备和本机入口，右侧选中文件与传输状态；底部最近传输。窗口窄时自然转为单列。
- Android：附近设备、当前发送对象与文件操作、最近传输依次排列。本机信息在标题栏入口，主要操作留在当前内容中。
- 无设备：解释同一 Wi-Fi 条件，提供刷新和手动连接；不展示虚构在线设备。
- 设备核对：点击设备后显示对方核对码，用户实际比较后确认。核对状态仅对应本次选择与当前证书；不暗示已经实现持久信任设备。
- 本机信息：查看本机核对码与地址，便于另一端核对或手动连接。默认主屏不常驻 IP、端口或长指纹。
- 发送：选择文件 → 明确文件和目标 → 发送 → 等待对方接收 → 进度 / 取消 → 校验 → 完成。取消和失败保留可理解的状态。
- 接收：前台请求用模态层，桌面居中、手机底部；显示来源、文件名、大小和拒绝 / 接收。名称不代表身份，绝不自动接受。系统返回键和 Esc 按拒绝处理。
- 历史：方向、设备、文件、结果。接收完成后 macOS 查看，Android 用系统保存界面导出。
